# Recommended repository spikes — 2026-09-27

User authorization: conduct spikes for the five shortlisted repositories.
This is isolated evaluation, with no production routing changes or adoption gate
based on favorable results. Prior datasets and archives remain frozen.

## Acceptance

1. Kev-4B: replay the frozen 32 agent-folder Choice cases twice through the public
   Space, calibrated on and date augmentation/permutation off. One excluded
   warmup. Preserve queue/client latency separately from model-reported timing.
   Stop and retain all receipts on quota, auth, timeout or invalid transport.
   A partial run cannot receive a full-corpus score or self-hosted speed claim.
2. CLM: preflight the reference encoder on available hardware. Exercise genuine
   released projection weights and typed schema on CPU if the full encoder is
   unavailable. Synthetic embedding tests prove component contracts only, never
   semantic accuracy. No substitute encoder can be labeled CLM-8B.
3. Laya-MLX: check actual supported platform and model-load prerequisites. A
   Linux failure cannot be scored as a model error or replaced by claimed Mac
   timing. Ask for an accessible Apple Silicon host while other work continues.
4. Compaction: run pinned upstream checks and freeze adversarial histories before
   live calls. Check call/result pairing, recent pins, unchanged original data,
   errors/fallback and content-blindness using matched metadata. Compare actual
   live keep/drop outcomes against independent retention requirements; failure
   to retain required evidence remains a failure even if compression is high.
5. Browser: run pinned offline tests and local isolated-browser checks. Freeze a
   local goal with an independent DOM validator before live calls. At most three
   live trials, 20 actions per trial. No external navigation, existing personal
   browser profile, login, purchase, sending or publication. Fault injection and
   live success must be reported separately. Model DONE is not the validator.

## Resource and integrity rules

Use existing local resources and configured credentials only. No rented GPU or
new paid account is provisioned. No keys are printed or included in artifacts.
The host is Linux x86_64, 12GB RAM, no detected NVIDIA device. main-mac currently
rejects SSH authentication; that failure and the user access question are kept.
Independent scripts must preserve actual source/model pins, raw responses,
errors, dependency versions, fixture hashes and exact commands. False completion,
false-safe decisions and dropped evidence are separate from overall correctness.
Worker drafts use the available GPT-5.6 Luna max fallback; actual backend identity
is not independently attested. Director reviews the work and performs final checks.

Study-specific plans and input hashes are frozen separately for each arm before
its live calls. API warmup and all setup/component work are accounted separately.
An unavailable arm has no invented score. Existing runtime paths stay optional.
